# FreeCAD-CommandTab-Modern

Theme package generated from the FreeCAD CommandTab modern icon pack.

## Coverage
- 1918 theme files exported
- 319 entries use CommandTab modern overrides
- 1599 entries mirror icon names from the local `FreeCAD-main` source tree
- 91 FreeCAD theme entries still use inherited/default artwork
- Inherits `FreeCAD-default` for any icon not overridden

## Source integration
- `FreeCAD-main` was detected and used to generate a wider FreeCAD-compatible theme pack

## Usage with IconThemes
1. Compile `icons.qrc` into an `.rcc` file if you have `rcc` installed.
2. Place the `.rcc` file into your FreeCAD `Gui/Icons` directory.
3. Select the theme with the `IconThemes` addon.
